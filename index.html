What changed, and why

  • Ambiguous values qualify themselves. A label only has to name its dimension when its value doesn't. Opus 5, High and web-search-agent stand alone; the moment two controls would both read Default, they become Model: Default and Agent: Default. The rule is computed from live state, not hardcoded, so it costs no width in the common case.
  • Agent outranks model. Which agent is answering changes its instructions and tools — a larger behavioural change than swapping model tiers. It is the last thing to retreat into overflow, not, as today, the item sitting furthest right in source order.
  • The context meter is never hideable, and it is labelled. Reserved slot beside send at every width. It is the one element here that is read continuously rather than set occasionally, and a bare ring makes you hover to learn anything.
  • It escalates. Muted below 75%, amber past 75%, red past 90%, with the token count appearing inline in the red. A ring that looks the same at 13% and 97% isn't doing the job a limit indicator exists to do.
  • Collapse the run settings. Auto, Default (recommended) and High are one concept — mode, model, reasoning effort. One chip, one popover, when space is tight.
  • Drop the qualifier from the trigger. Default (recommended) is a ~200 px label for a one-word value. "(recommended)" belongs in the dropdown list — where it is here.
  • Pin the primary action. Send is last in source order today, so it is the first thing stranded by wrapping. A fixed right-aligned slot matches every other chat UI.
  • Overflow, not wrap. Every setting stays reachable at the 300 px panel floor via ⋯; chrome is capped at one row at any width. The narrowest tier — agent alone — is retained as a safety net for long agent names such as web-search-agent, which can exceed the budget at 300 px even though the shorter Default fits.
